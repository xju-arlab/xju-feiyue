# 作业功能预览

当前采用学生收件箱 + 发布者收发台。HTML 可以直接打开，无构建和网络依赖；样式使用现有设计令牌，课程和状态标签采用 4px 小圆角。

- `01-inbox.html`：默认学生端。
- `02-collection.html`：默认发布端。
- `04-final.html`：两端合并预览，顶部切换身份。
- `03-board.html`：最初第三方案，仅保留作为历史对比。

## 最新设计约定

顶部原「班级空间」改为「分组任务」，导航为「概览 / 作业 / 点名 / 成员」。不显示「单人任务」大标题或介绍文案。

学生端每项作业一条，只保留课程胶囊、实验编号与可选名称、截止时间、提交状态和「上传」按钮，没有右侧详情。点击作业行或上传按钮打开文件选择器，整行也可接收文件拖拽；文件进入页面时轻微提示可放置区域，悬停当前行显示「松开即可上传」。上传按钮支持键盘操作。

选择文件后，在对应行显示文件名、大小与命名校验结果，命名正确后可确认上传，也可取消。各行的待上传文件相互独立，筛选不混用状态；重新上传在确认前保留原提交，取消或校验失败不会清除旧文件。页面会阻止文件在作业行外拖放时打开并覆盖预览，不拦截普通文本拖动。

发布端用简洁表格展示课程、实验、截止时间、提交人数和收齐状态。发布时设置课程、实验编号、可选名称、截止时间与文件命名规则；支持「班级-学号-姓名」和「班级-姓名-学号」两种顺序，并即时显示示例。

提交记录抽屉将命名规则和提交人数放在同一信息栏，每人一行展示姓名、文件名、提交时间、状态；姓名不重复展示学号。长文件名省略并保留完整悬停提示，窄屏仅记录区域横向滚动。

文件名与当前学生信息、当前任务规则精确匹配后才可提交。班级名称中的连字符直接参与整体比较，不按连字符粗略拆分。扩展名保留，单文件不超过20MB。每人状态仅为未提交/已提交，允许重新上传替换。

## 预览边界与验证

这是交互原型，不上传文件，不连接真实业务接口，状态仅在当前页面有效。刷新或点击重置恢复示例。各标签页的演示数据相互独立。

此前已在浏览器验证：错误文件名拦截、正确文件名提交、发布端人数更新、命名顺序实时预览、无名称实验发布、学生端继承发布规则、课程与状态筛选，以及桌面与窄屏布局。本次复验通过上传按钮与整行点击打开文件选择器、行内文件名/大小/校验提示、多行待上传状态隔离、错误替换保留原提交、取消文件，以及发布端单行提交记录。JavaScript 语法检查通过，控制台无错误。整行拖拽处理已实现并检查事件绑定，浏览器自动化通道不支持从系统文件拖入，因此未完成该路径的真实拖拽复验。

源码位于 `source/`。仓库根运行 `python3 artifacts/individual-tasks/source/build.py` 可重新生成页面。
